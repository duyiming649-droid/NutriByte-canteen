# NutriByte · HKUST 校园店 Campus Store · 3D 室内布局原型（MVP）

一个纯 Three.js 程序化搭建的餐厅室内原型：绿白品牌色、港式紧凑铺面、开放式透明后厨。
品牌 **NutriByte**，标语 **Eat well, Save time, Spend less**（场景内标语墙同步呈现：吃得好 · 省时间 · 花得少）。
全部几何体与贴图（菜单板、海报、霓虹灯牌、水磨石地面等）均由代码运行时生成，无外部素材，可离线运行；场景内标牌文字均为中英双语。

## 运行

ES 模块需要通过 HTTP 访问（直接双击 index.html 会被浏览器 CORS 拦截）：

- 双击 `start.bat`（自动打开 http://localhost:8137 ）
- 或手动：`python -m http.server 8137` 后访问 http://localhost:8137

## 空间规格

- 铺面 8.4m × 7.2m ≈ 60㎡，层高 3.0m，模拟港大校园紧凑铺位（ fronts 为落地玻璃 + 绿框玻璃门 ）
- 后厨带（z 3.2–7.2）约占 45% 面积，MVP 前店后厂一体：清洗、切配、批量烹煮、称重打包全在本店

## 分区

| 分区 | 位置 | 内容 |
| --- | --- | --- |
| 入口点餐 | 店外正门一侧 | 2 台自助 Kiosk 并排贴玻璃（屏幕朝街）；垂直于店面的单行排队走廊（双侧护栏）+ "请在此排队"立牌；店内右墙保留菜单板与克重参考展柜（1:1 食物模型） |
| 自提区 | 右侧 | 独立自提柜台、双层取餐架（贴标环保餐盒）、保温取餐柜、吊牌与地面导视 |
| 就餐区 | 左前 | 沿窗吧台 4 座 + 六人长桌 + 两张双人桌 ≈ 14–15 座（鼓励前一天预订，堂食少） |
| 开放厨房 | 中带 | 玻璃围挡装配线：4 格保温汤池、编号定量勺架、定量酱泵、KDS 厨房屏 |
| 后厨深处 | 后带 | 双星水盆、切配台、批量煮制炉头 + 汤锅、万能蒸烤箱、玻璃门冰箱、排风罩 |
| 打包称重 | 厨房中央岛台 | 电子秤、标签打印机、餐盒堆叠、配料盆 |
| 干货仓储 | 右后 + 左墙 | 货架、原料罐、周转箱 |

## 查看模式

- 底部按钮切换 6 个机位：总览 / 入口 / 就餐区 / 开放厨房 / 后厨深处 / 自提区
- `?snap=1&view=kitchen`：静态渲染模式（按需渲染，不跑 RAF），用于内嵌浏览器 / 自动化截图
- 控制台 `__audit()`：几何自检，报告悬浮（FLOAT）、下沉（SINK）、出界（OUT）、家具穿叠（HIT）

## 文件结构

```
index.html        页面外壳 + UI 覆盖层
start.bat         一键起本地服务
lib/              three.js r164 本地依赖（离线可用）
src/textures.js   程序化 Canvas 贴图（水磨石、瓷砖、木纹、菜单、霓虹…）
src/materials.js  共享 PBR 材质
src/props.js      道具库（桌椅、Kiosk、餐盒、保温柜、炉灶…）
src/layout.js     按坐标组装全店
src/views.js      机位预设 + 相机补间
src/main.js       渲染器、灯光、蒸汽动画、snap 模式、几何审计
```
